Finding the right CSS selectors

  1. Open the product page and press F12 (or Ctrl/⌘ + Shift + C).
  2. Click the inspect-element arrow, then click the element you care about.
  3. In the Elements panel, right-click the highlighted node → Copy → Copy selector.
  4. Paste it into the matching field here.
  5. Test it: back on the page, type document.querySelectorAll('your-selector') in the Console. You want exactly one match for the buy button.

Prefer stable attributes over generated class names. button[name="add"] or [data-testid="add-to-cart"] will survive a site redeploy; .css-1x7yhk9 will not. Full details are in the README.
